# Khelcom business

> Vitrine professionnelle d'une boutique d'électronique et d'électroménager à Nianing, Sénégal.

---

## 🚀 Démarrage rapide (Local)

**Prérequis :** Node.js

1. **Installer les dépendances :**
   ```bash
   npm install
   ```

2. **Configurer l'environnement :**
   Configurez les clés nécessaires dans votre fichier `.env` si applicable.

3. **Lancer le serveur de développement :**
   ```bash
   npm run dev
   ```

4. **Accéder à l'application :**
   Ouvrez [http://localhost:5173](http://localhost:5173) dans votre navigateur.

---

- **React 19** + **TypeScript**
- **Vite**
- **TailwindCSS**
